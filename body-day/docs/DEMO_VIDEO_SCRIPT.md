# BodyDay · 演示视频分镜与录制脚本（DEMO_VIDEO_SCRIPT）

> **状态：未录制。** 本机自动化浏览器环境使用软件渲染（SwiftShader），
> 无法录制出可用于提交的实时 3D 交互画面。因此本文件提供**可逐条执行的分镜、
> 操作步骤、配音文本与录制参数**，由人工在装有真实 GPU 的机器上一次性完成录制。
> **不提供伪造视频，也不以静态图冒充实时交互。**

## 1. 录制规格

| 项 | 建议值 |
|---|---|
| 时长 | 5–7 分钟（赛事上限 8 分钟） |
| 画幅 | 1600×900 或 1920×1080，浏览器窗口不含书签栏 |
| 帧率 | 30 或 60 fps |
| 音频 | 可选。若配音，使用下文口播文本；若无配音，必须烧入字幕 |
| 录制方式 | 系统录屏（QuickTime / OBS）或 `npx playwright codegen` 辅助定位 |
| 前置 | `npm run dev` 已启动；首屏进入前先清空浏览器缓存，**不要**预先访问过 /body（保证能拍到真实的加载过程） |
| 分辨率注意 | 三维页面加载需 20–50 秒，**录制时应剪掉这段等待**（或用「加速 ×8」字幕标注），不要把长加载放进正片 |

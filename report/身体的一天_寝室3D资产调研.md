# 《身体的一天》— 现实世界「单人大学生寝室」3D 资产调研

> 目标美术：Stylized / Low Poly / Hand-painted / Toon + Outline / Cozy / Indie / Minimal
> 参考：Make Me Pulse 2019（几何空间+氛围）、Messenger Web Game（小范围探索）、Sable（大色块+手绘感+极简）
> 交付形态：Web / Three.js / React Three Fiber
> 调研日期：2026-10-13

---

## 一、总体结论（先看这里）

1. **主力来源＝3 个 CC0 作者**：`Quaternius`、`Kenney`、`Kay Lousberg(KayKit)`。三者都是扁平色低模、免费商用、无需署名，**风格天然接近**，可作为寝室场景的统一底座。
2. **意外之喜**：`Kenney Furniture Kit` 本身就包含 `Computer Screen / Computer Keyboard / Laptop / Television`，**电脑（熬夜学习/熬夜游戏）无需另找来源**。
3. **最大缺口＝墙体/地板等"房间结构"**。三大家的基础包以家具为主，结构件少；Sable 式极简空间建议**用简单几何体自制墙地顶**，或复用 `Bubbly Bathroom Set` 的 walls/floors 件。
4. **风格统一的关键不在模型，而在 Shader**：Sable 的手绘线条感靠 `MeshToonMaterial + Outline(描边) + 顶点色/单色材质` 实现，模型来源只需保证是低模、非 PBR、非写实即可。

## 三、推荐组合方案

### 方案 A（首选 · 全 CC0 · 免署名 · 风格最统一）
```
房间结构：自制墙/地/顶(BoxGeometry) + Quaternius House Interior 的门/窗
核心家具：Kenney Furniture Kit（床/桌/椅/柜）
电脑组  ：Kenney Furniture Kit 的 Computer Screen + Keyboard + Mouse + Laptop
卫生间  ：Bubbly Bathroom Set + Quaternius House Interior 的 Bathroom Sink
生活用品：Quaternius House Interior（垃圾桶/绿植/顶灯/地毯）+ Poly Pizza 散件（书）
角色    ：Kenney Character Assets（换皮成大学生）
统一手段：MeshToonMaterial + Outline 描边 + 统一色板
```
- **风格统一性：高**。全部为扁平色低模，无 PBR，无写实。
- **版权：零风险**（全 CC0，无需署名）。
- **缺项**：牙刷/水杯需自制；墙体需自建。

### 方案 B（质感优先 · 混入 CC BY 精品件）
```
在方案 A 基础上，挑换关键"镜头特写"件：
电脑    → Sketchfab "Lowpoly Desk and Monitor"（含键盘鼠标耳机的一整套）
卫生间  → Sketchfab "Stylized Mint Low Poly Bathroom"（镜子质感更好）
耳机/书 → Sketchfab "Low Polly Stylized Headphones" + "Low Poly Books Set"
角色    → Sketchfab "Stylized Cute Girl Character"
```
- **风格统一性：中高**。需在 Blender 中统一材质为 Toon，并重着色到项目色板。
- **版权**：需在 credits 中署名（CC BY），维护一份 attribution 清单。

### 方案 C（Unreal/Godot 生态迁移 · 可选）
若后续换引擎，优先 `Quaternius`（FBX/OBJ/Blend/glTF 齐全，附 UE/Unity/Godot 工程）与 `KayKit`（glTF）。

## 四、风险分析

### 1. 版权不明确 / 需注意
- **CC BY vs CC0 混用**：Poly Pizza 大量单件是 `CC BY`（Poly by Google、Zsky），Sketchfab 绝大多数为 `CC BY`。**必须建立 attribution 清单**并在作品内注明作者+来源+许可。
- **AI 生成资产**：`heyheythere - PSX Furniture/Apartment Kit` 明确标注 "Made with AI assistance"。若比赛规则限制 AI 素材，应回避或谨慎使用。
- **平台外下载变体**：部分聚合站（如 asset-area）转载 Quaternius/Kenney 时标注混乱（有页面把 CC0 来源错标成 kenney.nl）。**始终以官方站点（quaternius.com / kenney.nl / kaylousberg.itch.io）为准**。
- **CGTrader/Fab 免费件**：许可各不相同（Royalty Free / "no AI" / 个人版），下载前逐条核对。
- **Sketchfab 非 CC 模型**：只选 `CC0 / CC BY / CC BY-SA` 且为 `Downloadable`，其余一律排除。

### 2. 风格冲突（需在后处理统一）
- **写实/PBR 模型必须剔除**：Sketchfab 上 "Isometric Bedroom"（100 万面，真写实）、"Computer Desk – Low Poly Game Ready"（**带 PBR 贴图**）等与 Sable 风格严重冲突，虽为 CC BY 也不建议用。
- **面数差异大**：Quaternius/Kenney 是百级面数，Sketchfab 精品常达 5k–40k 面；混用时需在 Blender 统一减面/降采样纹理。
- **纹理体系不一致**：KayKit 用单张 atlas，Quaternius 用纯色材质，Sketchfab 用独立贴图。**建议全部改为顶点色/纯色 + 统一色板**。
- **角色风格死角**：现有免费角色多为"奇幻冒险者"或"写实人体"，**没有天然的"中国大学生"**，需换皮/重着色，或自建低模主角。

### 3. 需要自己制作
- **墙体 / 地板 / 天花板**：三大家结构件稀少。极简空间建议直接自制（这也是 Make Me Pulse/Sable 的通行做法）。
- **牙刷 / 水杯 / 部分小物件**：体量小、来源杂，自制成本低于检索+适配。
- **Sable 式手绘描边效果**：无现成资产可给，需自研 `Outline` shader（法线外扩/后处理描边）。
- **主角（若追求高辨识度）**：建议基于 Kenney Character Assets 的骨架自建或换皮。

## 五、Three.js / React Three Fiber 适配分析

| 来源 | 提供格式 | 是否含 GLTF/GLB | R3F 导入难度 | 转换需求 |
|---|---|---|---|---|
| Kenney | OBJ / FBX / **glTF** | 是 | 低 | 无（glTF 直接可用） |
| Quaternius | FBX / OBJ / Blend / **glTF(GLTF)** | 是（poly.pizza 版） | 低 | 无；官网版建议 Blender 导出 GLB |
| Kay Lousberg / KayKit | OBJ / FBX / **GLTF** | 是 | 低 | 无 |
| Poly Pizza（平台） | OBJ / FBX / **GLTF** | 是 | 低 | 无 |
| OpenGameArt（Kenney 镜像） | OBJ (+Unity 包) | 否 | 中 | 需 Blender 转 GLB |
| Sketchfab | FBX / OBJ / Blend / GLB（视作者） | 部分 | 中 | 需 Blender 导出 GLB + 统一材质 |
| itch.io（Quin.GS） | 仅 FBX | 否 | 中 | 需转 GLB |
| itch.io（PSX Furniture） | GLB / FBX / OBJ | 是 | 低 | 无 |
| CGTrader / Fab | 视条目（BLEND/FBX/OBJ/GLB） | 部分 | 中 | 按需转换 |
| TurboSquid（.max/.usdz 等） | 非主流格式 | 否 | 高 | 一般不建议采用 |

**R3F 落地要点**
1. **统一格式 = GLB**：优先选原生 glTF 的来源；其余用 Blender 批量导出 GLB，并用 **Draco / Meshopt** 压缩。
2. **加载**：`useGLTF`（`@react-three/drei`）+ `Suspense`；多模型用 `useGLTF.preload` 预加载。
3. **材质改造**：加载后把 `MeshStandardMaterial` 换成 `MeshToonMaterial`（配 gradientMap 分阶），并用 `@react-three/postprocessing` 的 `Outline` 或自定义背面外扩实现描边。
4. **性能**：场景规模小，重点在**同屏 drawcall**——把同材质散件 `mergeGeometries` 或用 atlas 合并。
5. **动画**：角色用 `useAnimations`；Kenney/KayKit 角色自带动画剪辑，导入 GLB 后可直接调用。
6. **色彩统一**：项目自定义色板建议写在 `materials` 常量里统一注入，避免逐模型手改。

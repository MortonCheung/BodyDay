## 5. 未完成的验证（如实记录）

1. **移动端未做真机验收**：响应式布局已在浏览器视口（390×844）下检查无横向溢出，
   但**没有 iOS Safari / Android Chrome 的真机 / 模拟器截图验收记录**；触屏设备保留拆解滑杆（V2.1）。
2. **真实 GPU 帧率未采集**：本机验证使用的是软件渲染（SwiftShader），
   不能代表真实显卡性能，因此**本报告不给出任何 FPS 或性能分数**。
3. **拆解的产品级视觉分离仍在打磨**：分层位移与外壳渐进隐去已落地并实测可见，
   但内部层间距仍可继续加大（当前每层额外位移 = 人体包围盒半径 × 0.17）。
4. **多版本浏览器兼容性仅覆盖 Chromium 140**：Firefox / Safari 未做实测。
5. **作品尚未在任何平台提交**（赛事截止 2026-10-18）。
6. **V2.1 未做连续跨尺度转场**：目前是「镜头推进 + 明确的继续深入入口」，**不声称** GLB 能连续放大到细胞级。
7. **V2.1 肾 / 膀胱未新增专题**：真实模型里 `urinary` 仅 3 个网格，不足以支撑专题，只保留基础展示。
8. **V2.1 中性化的可见代价**：中性化是**中性化展示**、不是新建无性征人体；骨盆近观时会看到该处被移除外壳后露出的真实肌肉 / 骨盆结构（解剖切口观感），已如实记录，未用遮挡方块掩盖、也未改成医学上错误的形态。

这些缺口不影响已声明功能的可用性，但**不声称已完成**。

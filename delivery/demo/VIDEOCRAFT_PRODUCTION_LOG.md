## 2. 制作方式与工具

| 项目 | 实际使用 |
|---|---|
| 浏览器与录制 | Playwright（Chromium）`recordVideo`，真实输入驱动（滚轮 / 点击 / 拖动 / Esc） |
| 录制脚本（随源码交付） | `body-day/scripts/record-final-video.mjs` |
| 转码与封装 | `ffmpeg`：`libx264 -preset medium -crf 23 -pix_fmt yuv420p -r 30 -movflags +faststart` |
| 剪辑软件 | 无。整段为**一次连续录制**，不做拼接、不加特效、不改画面内容 |
| 渲染后端 | ANGLE / SwiftShader **软件渲染**（无 GPU 的自动化环境） |

录制命令（可复现）：

```bash
# 前置：先起开发服务器（本机实测 http://localhost:5173）
cd body-day && npm run dev
# 录制（另开终端）
cd body-day && BODYDAY_BASE_URL=http://localhost:5173 node scripts/record-final-video.mjs
```

| 5d | 点选一个未登记的真实细分结构 | 体表（皮肤）：右栏有真实名称，**没有**「查看器官详解」入口（不造假按钮） |

> **诚实说明（重要）**：第 5a、5c 段的「点选心 / 脑」**没有成功命中目标器官**——

## 6. 哪些画面可复现、哪些不可

**可复现**（重跑 `record-final-video.mjs` 即得同类镜头）：
- 开场加载与同节点形变、完整人体、旋转、滚轮拆解与组装、右栏卡片替换、器官详解进入与返回、
  器官页卡片、关于页。
- 脚本用**路由 + 屏幕坐标 + 页面自报读数**定位，不依赖易变的 DOM 类名，界面改版后仍可复跑。

**不可完全复现**（如实标注）：
- **点选的具体命中结构**会随视角与软件渲染的浮点差异变化（第 5a 段本次为左肺下叶）。
- **成片流畅度**：本机为 SwiftShader **软件渲染**，帧率明显低于真实 GPU；成片按 30 fps 封装，
  但实际渲染节拍低于 30 fps，**不能代表真实显卡上的性能**（本作品也**未采集真实 GPU 帧率**）。
- 若需要更高规格 / 带讲解的版本，请在装有真实 GPU 的机器上按 `DEMO_VIDEO_SCRIPT.md` 重录。

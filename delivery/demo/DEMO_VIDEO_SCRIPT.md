# BodyDay · 演示视频分镜与录制脚本（DEMO_VIDEO_SCRIPT）

> 本文件对应 **2026-10-18 最终成片** `delivery/demo/BodyDay_最终演示.mp4`
> （1920×1080，H.264，真实浏览器录屏，≤8 分钟），同时保留为**后续重录 / 补录**用的分镜脚本。
> **成片时长以 `delivery/demo/VIDEOCRAFT_PRODUCTION_LOG.md` 里的 ffprobe 实测为准**，本文件**不写任何具体秒数**。
>
> **关于制作方式（如实说明）**：本机**不存在 VideoCraft skill**（已全盘搜索 + 检查已配置 skills 清单，均无命中），
> 因此按施工手册 §9.1 采用退路：**真实浏览器录屏 + 本地剪辑（ffmpeg）**。
> **不提供伪造视频，也不以静态图冒充实时交互。**
> 旧 `delivery/demo/bodyday-v2-walkthrough.mp4` 属**上一轮版本录像**，已被 `BodyDay_最终演示.mp4` 取代。
>
> 本版分镜与**当前实现一致**：全片始终是同一个中央三维人体与同一根右栏**「当前对象」**信息栏；
> 主导航只有**三项（人体探索 / 器官详解 / 关于）**；**不再有顶部双模式开关、五项层级导航、左侧常驻结构目录与步骤引导条**；
> 拆解由**鼠标滚轮**驱动、桌面端无滑杆；入口为**同节点形变**。

## 1. 录制规格

| 项 | 建议值 |
|---|---|
| 时长 | 最终成片 **≤ 8 分钟**；**具体时长以 `delivery/demo/VIDEOCRAFT_PRODUCTION_LOG.md` 的 ffprobe 实测为准**（本文件不写具体秒数） |
| 画幅 | **1920×1080**（最终成片）；浏览器窗口不含书签栏 |
| 帧率 | 30 或 60 fps |
| 音频 | 可选。若配音，使用下文口播文本；若无配音，必须烧入字幕 |
| 制作方式 | **本机不存在 VideoCraft skill** ⇒ 采用**真实浏览器录屏**（QuickTime / OBS 或自动化录制）+ **本地 ffmpeg 剪辑** |
| 前置 | `npm ci` 后 `npm run dev`（或 `npx vite --port 5175 --strictPort`）；进入前先清空浏览器缓存，**不要**预先访问过 `/body`（保证能拍到真实的封面加载与同节点形变过程） |
| 加载提示 | 整具人体模型**随作品发布在本地**，就绪耗时实测约 1 秒，**无需再剪掉长等待**；如页面较慢，仅需把封面进度条一小段加速标注 |
| 拍摄范围 | 全程围绕**同一具人体**与**同一根右栏「当前对象」**取景；重点在「封面真实加载 + 同节点形变」「完整人体」「转动 / 系统筛选」「滚轮拆解」「点结构 → 右栏联动」「进入器官详解」「返回并恢复状态」「关于 / 署名」 |

## 2. 分镜表（按最终镜头顺序）

| 镜号 | 画面与操作 | 口播 / 字幕文本 |
|---|---|---|
| 1 · 开场：真实加载与同节点形变 | 打开 `/`（已清缓存）。显示**独立暖白封面**，封面内是**真实字节进度**（形如「真实资产 31.8 MB · 已加载 12.4 MB」）；突出入口是**同一个 DOM 节点**——先是一条 240×3 px 细进度条，模型真正就绪后**原地形变**为约 148×44 px「进入探索」按钮（形变完成 `data-settled="true"` 前 `disabled`），点击进入 | 「这不是一张封面图：封面上的数字是模型真实的字节进度。等它真正装配完成，这条细进度条会在原地变成『进入探索』按钮——不是假倒计时；在那之前它点不动。」 |
| 2 · 完整人体 | 进入 `#/explore`，呈现**完整人体**（默认已中性化）。缓慢环绕，展示它是一具可转动的真实三维人体而非贴图 | 「全片只有这一个界面：中间是同一具真实人体，右边跟着你选中的『当前对象』变化。人体、系统、器官、细胞的差别，只体现在镜头移动到哪、右栏显示什么。」 |
| 3 · 转动与系统筛选 | 拖动旋转人体；演示桌面**左操作栏**（**只在整具人体可被筛选的页面出现**）的**系统筛选**按钮组：切换神经 / 循环 / 淋巴系统并聚焦；显示「当前对象」状态；演示 ≤1024px 收起左栏、≤900px 右栏变底部抽屉 | 「转动它，它是一具真的会转的三维人体。左栏只在能筛选整具人体的页面出现——点系统名，人体就只显示那一个系统。」 |
| 4 · 滚轮拆解 | 回到完整人体，用**鼠标滚轮**向下拆解到约 42%——体表外壳渐进隐去、内部按**解剖系统分层**径向分离；再向上滚反向组装（回到约 21%）。桌面端**已无拆解滑杆**（触屏才保留） | 「滚轮驱动的是真实几何位移：按解剖系统把结构一层层向外平移，皮肤随进度先变半透明、再移出画面。位移随进度重算，来回滚不会越拆越歪。」 |
| 5 · 点选心 / 脑 / 肺 → 右栏同步 | 在拆解态点选心脏 / 大脑 / 肺等结构；右栏「当前对象」同步更新（已登记实体科普卡，或**通用结构卡**：标题 + 至多一条「大脑 · 额叶」式路径 + 一句真实空间 / 结构说明）；匹配到**已核实器官**时出现**唯一**的「查看器官详解 →」。再点空白或按 `Esc`：取消选中，**相机恢复到选中前的真实视角**（实测 positionDelta = 0、targetDelta = 0） | 「点中间的结构，右边立刻切成它的『当前对象』卡。点空白或按 Esc，会回到你刚才的真实视角——位置的误差实测为 0。」 |
| 6 · 进入器官详解 | 从右栏唯一的「查看器官详解 →」进入 `#/detail/heart`，再依次展示脑 / 肺 / 脾。镜头聚焦并隔离该器官，右栏只讲当前器官本身 | 「被核实过的器官才有这唯一的入口。器官详解页把镜头推到器官上、隔离其余结构，右栏只讲它本身。」 |
| 7 · 返回并恢复状态 | 在器官详解页点「返回探索」回到人体探索；展示返回后相机与选中状态按预期恢复 / 清空（实测恢复误差 0） | 「返回探索后，状态按预期恢复——不会把你丢到一个莫名其妙的视角。」 |
| 8 · 关于 / 署名 | 打开封底 `#/about`（此处 `canvas = 0`，唯一的非三维阅读页）。缓慢滚过作品定位、**19 条来源表**、模型许可与标明修改（CC BY-SA 4.0）、科学免责声明（含「拆解」边界说明），以及「作品的可访问页面（**16 页**）」索引表 | 「最后一页是来源、版权与边界。人体解剖来自公开图谱 Z-Anatomy，许可是 CC BY-SA 4.0，我们对模型的改动都已标明，包括默认展示的中性化。这里的每一句结论都标了来源，这不是医疗建议。」 |

## 5. 录制检查清单

- [ ] 浏览器已清缓存，能拍到「封面真实进度 → 就绪 → **同一 DOM 节点**细进度条形变为『进入探索』按钮」的真实过程
- [ ] 拍到形变完成（`data-settled="true"`）前按钮 `disabled`，**不是假倒计时**
- [ ] 拍到封面**不自动进入、不自动淡出**，点击「进入探索」后才揭示内部
- [ ] 明确拍到「**一个工作台**」：中央人体 + 右栏「当前对象」，且换页时**没有换外壳 / 重挂场景**
- [ ] 拍到主导航只有**三项（人体探索 / 器官详解 / 关于）**，左上角 BodyDay 标识回到人体探索
- [ ] 拍到**左操作栏只在整具人体可被筛选的页面出现**（人体探索 / 人体总览 / 系统页），器官页 / 细胞页 / 器官详解页无左栏
- [ ] 拍到用「**鼠标滚轮**」驱动真实几何位移（体表渐进隐去 + 按解剖系统分层分离；**桌面端已无拆解滑杆**）
- [ ] 拍到默认人体**中性化**（无外生殖器细节；如需近观，注明属中性化展示）
- [ ] 拍到「点结构 → 右栏『当前对象』联动（**其余结构淡化而非消失**）」，以及通用结构卡与已登记科普卡两种形态
- [ ] 拍到**取消选中后相机恢复选中前视角**（点空白 / Esc / 返回上一级语义一致）
- [ ] 拍到唯一「**查看器官详解 →**」进入 `#/detail/*`，并拍到器官详解的心 / 脑 / 肺 / 脾四页
- [ ] 拍到器官详解页「**返回探索**」并展示返回后状态按预期恢复
- [ ] 封底 `/about` 的来源表、许可与标明修改、免责声明、**16 页索引表**拍到
- [ ] 总时长 **≤ 8 分钟**
- [ ] 成片为**真实运行录屏**，未使用静态图冒充交互；制作方式为**真实浏览器录屏 + 本地 ffmpeg 剪辑**（本机不存在 VideoCraft skill）

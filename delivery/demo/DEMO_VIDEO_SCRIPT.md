> **状态：已录制。** 体验录像已真实产出：`delivery/demo/bodyday-v2-walkthrough.mp4`
> （1440×900，H.264，由真实浏览器录制，覆盖「启动封面 → 进入 → 旋转 → 拆解 30/62/100% →
> 点心脏 → 进入心脏页 → 人体 → 大脑 → 神经元 → 脾脏 → 白细胞 → 关于」的完整链路）。

## 1. 录制规格

| 项 | 建议值 |
|---|---|
| 时长 | 5–7 分钟（赛事上限 8 分钟） |
| 画幅 | 1440×900（现有成片）或 1600×900 / 1920×1080，浏览器窗口不含书签栏 |
| 帧率 | 30 或 60 fps |
| 音频 | 可选。若配音，使用下文口播文本；若无配音，必须烧入字幕 |
| 录制方式 | 系统录屏（QuickTime / OBS）或浏览器自动化录制 |
| 前置 | `npm ci` 后 `npm run dev`（或 `npx vite --port 5175 --strictPort`）；进入前先清空浏览器缓存，**不要**预先访问过 `/body`（保证能拍到真实的封面加载过程） |
| 加载提示 | 整具人体模型**随作品发布在本地**，就绪耗时实测约 1 秒，**无需再剪掉长等待**；如页面较慢，仅需把封面进度条一小段加速标注 |
| 拍摄范围 | 全程围绕**同一具人体**与**同一条右侧纸条**取景；重点在「封面闸门」「拖动拆解」「点结构 → 右侧联动」「进入器官 / 下潜细胞」 |

## 2. 分镜表

| 镜号 | 时长 | 画面与操作 | 口播/字幕文本 |
|---|---|---|---|
| 1 | 0:00–0:30 | 打开 `/`。显示**独立暖白封面**，封面内是真实字节进度（形如「真实资产 31.8 MB · 已加载 12.4 MB」）；模型真正装配完成后才出现「进入探索」，点击进入；**没有自动进入、没有自动淡出** | 「这不是一张封面图：封面上这行数字是模型真实的下载字节。等它真正装配完成、渲染出第一帧，才出现「进入探索」——在那之前，里面什么都点不到。」 |
| 2 | 0:30–1:10 | 进入后呈现**完整人体**。转动人体，展示它不是一张图；拖动底部「**拆解**」滑块到约 30%，体表开始渐进半透明 | 「全片只有这一个界面：中间是同一具真实的人体，右边是随选中变化的知识纸条。它不换页面外壳——人体、系统、器官、细胞的差别，只体现在镜头移动到哪、右侧显示什么。」 |
| 3 | 1:10–2:00 | 继续拖动「拆解」到约 62% → 100%：体表外壳渐进隐去，内部按**解剖系统分层**径向分离（体表 → 肌肉 → 骨骼 → 内脏 → 深部调节系统）；镜头随位移后的整体包围盒拉远，人体整体始终留在画面内 | 「中间这根滑块是真实的几何位移：它按解剖系统把结构一层层向外平移，越靠内推得越远，皮肤则随进度先变半透明、再移出画面。位移随进度重算，所以来回拖动不会越拆越歪。」 |
| 4 | 2:00–2:45 | 在拆解态（约 50%）**点中心脏所在的屏幕位置**：右侧立即出现完整心脏知识卡，并提示「你点到的是「Right_ventricle」，它归属心脏」。再点右侧「**进入心脏（单独观察）**」进入器官页 | 「这就是核心交互：点中间的结构，右边立刻换成它的知识。点到的哪怕是一小块，也会如实告诉你它在解剖上归属哪块结构。」 |
| 5 | 2:45–3:30 | 进入 `#/organ/heart`：镜头推进到心脏、其余结构隐去（**隔离**）。滚动到关系区，展示「心脏 — 白细胞」被标注为**循环输送** | 「器官页把镜头推进到心脏、其余结构暂时隐去。这里还澄清一个常见误解：白细胞只是随血液流经心脏，心脏提供的是循环动力，不生成白细胞。」 |
| 6 | 3:30–4:15 | 回到人体 → 进入 `#/organ/brain`（聚焦 + 隔离）→ 在右侧点「**进入神经元**」跨尺度下潜到 `#/cell/neuron` | 「从脑可以继续往下，进入神经元——这是一条真实登记的尺度延伸关系，不是随便跳转。」 |
| 7 | 4:15–5:00 | 神经元页：点选**胞体 / 树突 / 轴突 / 髓鞘**四个部件，右侧知识随部件联动 | 「神经元是本作品程序化生成的原创几何：胞体负责整合、树突负责接收、轴突是输出端、髓鞘让信号传导更快，点哪一块，右边就讲哪一块。」 |

## 5. 录制检查清单

- [ ] 浏览器已清缓存，能拍到「封面真实进度 → 就绪 → 手动进入」的真实过程
- [ ] 拍到封面**不自动进入、不自动淡出**，点击「进入探索」后才揭示内部
- [ ] 明确拍到「**一个工作台**」：中央人体 + 右侧一条知识纸条，且换页时**没有换外壳 / 重挂场景**
- [ ] 拍到拖动「**拆解**」滑块使真实几何位移发生（体表渐进隐去 + 按解剖系统分层分离）
- [ ] 拍到「点结构 → 右侧『当前选中』联动」与「Esc / 取消选中」两处
- [ ] 拍到三个系统页与三个器官页的镜头聚焦（聚焦 / 隔离）
- [ ] 拍到「进入心脏（单独观察）」页面级入口，说明器官页不是孤页
- [ ] 拍到大脑 →「进入神经元」与脾脏 →「查看白细胞」两条跨尺度链路
- [ ] 拍到心脏 → 白细胞被标注为「循环输送」、**不生成白细胞**
- [ ] 细胞页拍点选部件与右侧联动
- [ ] 封底 `/about` 的来源表、许可与标明修改、免责声明、11 页索引表拍到
- [ ] 总时长 ≤ 8 分钟
- [ ] 成片为**真实运行录屏**，未使用静态图冒充交互

# BodyDay · 身体的一天

> 面向 2026 辽宁省大学生科普设计大赛「非医类健康科普赛道」的**跨尺度交互式健康科普 H5 作品**。
> 中央始终是**同一具可以转动的完整人体**，点模型上的结构，右侧信息栏随当前选中联动。
> 人体 → 系统 → 器官 → 细胞之间的差别，只体现为**镜头与右栏内容的变化**，
> 不换页面外壳、不重挂三维场景。

主导航只有三项：**人体探索 / 器官详解 / 关于**。左上角 BodyDay 标识点击回到人体探索，
它不是另一具人体首页；原先的「自由探索 / 引导教学」双模式开关与五项层级导航已全部删除。

## 快速开始

```bash
cd body-day
npm install          # 或 npm ci（锁定文件匹配时）
npm run dev          # 开发模式 → http://localhost:5173/
```

生产构建与本地预览：

```bash
npm run build        # tsc -b && vite build，产物在 dist/
npm run preview      # 预览生产构建 → http://localhost:4173/
```

质量检查：

```bash
npm run lint         # oxlint
npm run test         # vitest（领域数据完整性 + 结构卡 + 器官桥接 + 程序化细胞几何）
```

## 操作方式

| 输入 | 行为 |
|---|---|
| 左键拖动 / 单指拖动 | 旋转模型 |
| 滚轮（**未选中**结构时） | 向下逐层拆解、向上反向组装（可逆，不累计偏移） |
| 滚轮（**已选中**结构时）/ 双指捏合 | 缩放，观察当前结构 |
| 右键 / 双指平移 | 平移 |
| 单击结构或热点 | 选中：当前结构强调，其余结构**淡化而不隐藏**，右栏换成对应知识 |
| 「返回上一级」 | 回到上一次点选的层级 |
| 空白处单击 / Esc | 取消选中，**相机回到选中前的视角**（位置、目标与取景一并恢复） |
| 「查看器官详解 →」 | 只在当前对象已核实对应器官时出现的**唯一**跨页入口 |
| 「返回探索」 | 从器官详解回到人体探索，并恢复进入前的选中 / 展开程度 / 相机 |
| Tab / Enter / Space | 键盘遍历与选中结构 |
| `prefers-reduced-motion: reduce` | 所有动画降级为**瞬时**，不播放转场 |

## 两条可交互的贯通路线

1. **人体 → 大脑 → 神经元 → 胞体 / 树突 / 轴突 / 髓鞘 → 返回**
2. **人体 → 脾脏 → 白细胞 → 细胞膜 / 细胞质 / 细胞核 → 返回**
3. 另有 **心脏 → 循环 → 白细胞** 的功能关联路线，关系类型显式标注为「循环输送」。

器官详解页当前覆盖已在 `src/integrations/organBridge.ts` 中**人工核实**的四个器官：
**心脏、大脑、肺、脾脏**。未核实映射的结构只保留「当前结构」知识卡，不显示入口、不造假按钮。

## 技术栈与架构

React 19 + TypeScript + Vite 8 + Three.js / React Three Fiber / Drei，单页应用（HashRouter）。

```
src/
  app/          路由解析（resolveView）、稳定外壳、启动闸门状态机、页面索引
  domain/       纯数据：实体、科学关系、内容资产脚本、来源表、系统表、结构卡
  integrations/ 器官桥接表（organBridge，人工核对的 ID 映射）
  services/     atlas 加载与结构映射、本地学习记录、署名文本
  design/       设计令牌、排版、版面、组件、舞台样式、交互与动效令牌
  three/        三维舞台（人体 / 细胞）、程序化细胞几何、按需加载入口、拆解位移内核
  components/   共享 UI：知识卡、来源列表、错误边界与降级
  features/
    startup/    启动封面闸门（同节点形变入口）
    workbench/  空间工作台（三栏：左操作 / 中央舞台 / 右信息）
    about/      封底阅读页
  legacy/dorm/  旧「寝室 3D Demo」代码（归档保留，不在新应用入口中）
```

关键工程决策（详细说明见 `docs/ARCHITECTURE.md`）：

- **路由不拆分组件树**：`resolveView` 把 URL 解析成视图，`AppShell` 只用同一个 `ExploreWorkbench`
  渲染所有探索页，使三维场景在整段探索中始终挂载、不重新加载。
- **取景交给舞台**：选中并请求聚焦目标结构，由舞台遍历真实网格算包围盒决定机位
  （`body-shell` 全身 / 系统根结构 / `cerebrum`·`heart`·`spleen` 器官）。
- **真实几何拆解**：读取 GLB `extras` 按解剖系统分层对**真实网格**做径向位移，
  位移由进度重算、从不累加；体表外壳随进度渐进隐去。**这不是** Human Atlas 式的
  前视平面二维投影打包，作品不声称具备该能力（见 `THIRD_PARTY_NOTICES.md`）。
- **三维运行时按需加载**：`three` + R3F 被打进独立分块（约 246 KB gzip），
  只有进入三维页面才下载；封底 `#/about` 的首屏不承担这部分体积（实测 `canvas = 0`）。
- **结构清单折叠**：同一器官下的细分结构归并为一项，内部 ID（如 `body-shell`）不展示给用户。
- **错误边界与降级**：WebGL 不可用、上下文丢失、模型加载失败都不会白屏 ——
  舞台内显示明确说明与重试入口，页面其余内容保持可用。

## 科学与版权边界

- 人体模型来自随包分发的 **Z-Anatomy 1.4.0 整具人体**（上游 Z-Anatomy / Vanatome，**CC BY-SA 4.0**）；
  细胞几何为 BodyDay **程序化原创**。
- 科普内容对齐《中国公民健康素养——基本知识与技能（2024年版）》方向，
  关键信息交叉核对 WHO / NIH / CDC 与 OpenStax 开放教材，逐条标注来源编号。
- 本作品**不构成医疗建议**；三维模型为科普示意，不按真实比例，标注点未做逐点解剖配准。
- 完整声明见 [`THIRD_PARTY_NOTICES.md`](./THIRD_PARTY_NOTICES.md)。

# 01 · 产品行为规格（BodyDay V2）

> 本文件定义 V2 的用户可见行为。与 V1 相反的部分以本文件为准（对应补充指令决策 1）。
> 记录时间：2026-10-15。基线与技术事实见 `00_BASELINE_AND_FEASIBILITY.md`。

---

## 1. 产品定位

面向普通用户的**连续空间探索式健康科普作品**。

用户不需要知道 Vanatome / BodyParts3D / GLB / Mesh / React / Route / 内部结构 ID / 文献编号，
只需要自然地完成：

**看见人体 → 探索身体 → 拆开结构 → 找到器官 → 放大观察 → 进入微观世界 → 理解身体与健康的关系。**

V2 只保留**一种**默认探索体验：以三维模型为主要入口。不再有「自由探索 / 引导教学」的模式选择。

---

## 2. 启动流程：独立加载封面 + 人工进入

### 2.1 状态机

```
loading ──(网格装配完成 + 首个有效帧)──▶ ready-to-enter ──(用户点击「进入探索」)──▶ entering ──▶ exploring
   │
   └──(加载失败)──▶ error ──(重试)──▶ loading
```

| 状态 | 用户可见 |
|---|---|
| `loading` | 全屏暖白封面：品牌名、简短副标题、**真实**加载进度、低干扰动效。**不暴露内部界面。** |
| `ready-to-enter` | 封面出现「进入探索」。**不自动进入。** |
| `entering` | 封面做一次性过渡动画后消失，揭示已就绪的三维人体。 |
| `exploring` | 正常探索。此状态之后不再出现封面。 |
| `error` | 仍在封面上，显示简明原因 + 「重试」。不开放「进入探索」，不暴露内部工作台。 |

### 2.2 行为规则（全部可验收）

1. **不自动进入**：用户不点击，永远停留在封面。
2. **不提前暴露**：慢速网络下只能看到封面，看不到导航、知识面板或加载占位。
3. **就绪判定是真实的**：`catalog` 加载成功 ≠ GLB 可渲染。判定依据为
   「查看器/舞台报告全部必需模型装配完成」**再等一个有效渲染帧**（`requestAnimationFrame`）。
   下一章（Phase B）会把它抽象成**引擎无关**的 `loading → ready-to-enter → entering → exploring`
   契约，各引擎各写一个适配器，避免换引擎时返工。
4. **真实进度**：`onLoadProgress({loaded,total,percentage})` 提供真实字节进度；
   `catalog.json` 每个 bundle 自带 `bytes`，可算真实总量。**拿不到总量时显示不确定进度动画，不伪造百分比。**
5. **进入后不二次加载**：点击「进入探索」不得再经历一次完整人体加载。
6. **Canvas 保持真实尺寸**：后台预渲染用真实尺寸的 Canvas（不可 `display:none`），避免相机宽高与 WebGL 初始化异常。
7. **未进入前禁止交互**：封面覆盖层拦截指针，并用 `inert` 屏蔽内部键盘焦点。
8. **不依赖固定等待时间**：不得用 `setTimeout` 假定加载完成。
9. **防重复入场**：用 nonce/ref 守卫，避免 StrictMode 重复 effect 造成重复请求或重复入场。
10. **重试不成环**：失败重试有上限保护，不产生无限循环。
11. **冷启动 / 刷新 / 深层链接**：三者都要正确处理。封面是**应用级启动闸门**（按会话只出现一次），
    不是某条路由的装饰；进入后停在 URL 所指向的位置。
12. **初始加载范围**：首屏只要求「完整人体」就绪；细胞等非必需资源按需或后台预加载。

## 4. 各探索状态的行为

### 4.1 人体总览（默认状态）

- 完整人体位于视觉中央，且**占据主要可用宽度**（不再被两侧面板挤压）。
- 交互：左键拖动旋转；滚轮**控制拆解程度**；点击预设部位；点击空白或按 Esc 取消选中。
- 拆解：`explosionProgress 0 → 1` 连续插值。0 = 组装，且**人体轮廓仍可辨认**；
  1 = 目标拆解布局（结构之间不重叠、不随机飞散）。
- 未选中任何结构时：只保留极少引导文案，**不展示**完整解剖知识长文，**不显示**复杂参数或导航菜单。

### 4.2 结构选择（人体上的点击）

悬停 → 克制的高亮/轮廓 → 点击 → 系统确认「真实存在、可展示、已映射到科普实体」→
镜头平滑聚焦（基于**真实网格包围盒**，不使用已被证实不可靠的 atlas metadata `position` 作为唯一相机坐标）→
必要时周围结构渐隐 → 右侧展开**精简知识卡**。

拖动旋转不得误触发选择（指针位移阈值）。

### 4.3 器官探索

- 镜头平滑聚焦；其它不相关结构适当隐去；当前器官保留自然空间尺度。
- 可旋转、可缩放；右侧为可收起的精简知识卡。
- **滚轮语义切换**：进入器官/细胞状态后，滚轮改为相机缩放。
- 右侧禁止堆满模型 ID、来源编号、内部数据表、技术说明。

### 4.4 细胞探索

- 视觉体系与器官层**一致**，不突然变回"课程管理界面"。
- 沿用现有原创模型：`NeuronModel` / `LeukocyteModel` / `CellStage` / `cellGeometry`。
- 可选中真实细胞部件，操作方式与器官层一致。

### 4.5 滚轮语义（必须明确，不允许同时发生）

| 当前状态 | 滚轮作用 |
|---|---|
| 人体总览 | 拆解程度（0→1 连续） |
| 器官 / 细胞探索 | 相机缩放 |
| 指针在纸条/知识面板上 | 正常阅读滚动，**不劫持** |
| 触屏 | 不劫持整页滑动；提供简洁拆解手势或替代控件 |

事件仅在对应三维操作区域内生效；不应导致网页意外跳动；能区分触控板捏合时保留正常缩放；
在「拆解完成 / 器官聚焦 / 返回人体」之间必须恢复正确输入模式。

## 5. 层级与返回

层级契约：`body → system → organ → cell → cell-part`（不要求每级都存在，但必须可验证）。

每一级记录：当前对象 ID、科学实体类型、父级、已加载模型、支持的子级、当前相机状态、返回目标、科普实体。

返回机制要求：
- 返回**上一级**，而不是每次都跳回完整人体
  （示例：完整人体 → 神经系统 → 大脑 → 神经元 → 大脑 → 神经系统 → 完整人体）。
- 某级没有独立视觉层时可跳过该级，但上下文必须合理。
- 应尽量保存上一级的相机方向、可见图层与拆解程度，使返回自然。
- **禁止**「任意器官 → 任意细胞」的通用兜底跳转。

## 6. 知识与来源的展示位置

| 内容 | 探索界面 | 「关于」 |
|---|---|---|
| 结构名称、它是什么、如何工作、与健康行为的关系 | ✅ 精简知识卡 | 可全文 |
| `S01/S02` 文献编号、来源机构列表 | ❌ | ✅ |
| 模型项目署名、开源技术说明、参考链接集合 | ❌ | ✅ |
| 版权许可长文本、免责声明 | ❌ | ✅ |

**移除展示不等于删除依据**：科学知识与来源 ID 的映射、医学事实审查记录、第三方依赖与模型许可、
免责声明、完整版权与署名全部保留，并集中在「关于」提供明确入口。
若具体许可证对署名位置、可访问性、授权链接或修改声明有要求，必须满足许可条款，不得为视觉简洁而违反。

## 7. 无障碍与动态效果

- 支持 `prefers-reduced-motion`：用户关闭动态效果时使用即时切换或低动态替代，且不影响正常操作。
- 键盘可达：封面「进入探索」、返回/复位、知识卡收起等关键操作均可键盘触发。
- 选中与聚焦状态变化通过 `aria-live` 播报；Canvas 有 `ariaLabel`。

## 8. 页面计数口径（与赛事要求对齐）

赛事要求：H5 交互式作品**原则上不少于 10 页（含封面、封底），总页面控制在 20 页以内**。

| 类别 | 路径 | 说明 |
|---|---|---|
| 封面 + 人体总览 | `/` | 首屏启动封面 → 进入后为人体总览 |
| 人体总览（直达） | `/body` | 深层链接直达，不重复出现启动封面 |
| 解剖系统 | `/systems/:id` | 覆盖全部 11 个解剖系统，各自有真实结构与真实简介 |
| 器官 | `/organ/brain`、`/organ/heart`、`/organ/spleen` | |
| 细胞 | `/cell/neuron`、`/cell/leukocyte` | |
| 封底 | `/about` | 完整来源、许可、免责声明、页面索引 |

**可直达路径总数 19 条**，落在 10～20 页区间内。

**计数方法的不确定性如实声明**：
本作品为单页应用，同一界面在不同状态下的视觉差异不当作独立页面计数；
`PAGE_INDEX` 只收录其中 11 个核心页面，其余系统页作为可直达路径补充。
若评委采用不同的页面计数口径，以「每个路径都有真实内容与真实交互，且附独立截图」为可核查依据。

## 9. 明确不做（本轮）

不重做寝室生活模拟；不做 AI 问答；不做登录；不做后端数据库；不做无依据的医学预测；
不开发新的教学课程体系；不为凑数增加无内容的器官；不整体复制 Human Atlas；
不为技术指标牺牲体验；不新建无关工程；不修改其它竞赛仓库；不把未验证代码自动覆盖到 main；
不擅自修改已确定的科学结论。

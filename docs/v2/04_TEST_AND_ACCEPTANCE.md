## 2. 真实浏览器验收（逐条问题与读数）

验收脚本用**相机投影出的真实屏幕坐标**去点击具体器官，因此「能不能点中」不靠肉眼判断。

### Q1 现在打开会发生什么

| 读数 | 值 |
| --- | --- |
| 首屏封面状态 | `loading` → `ready`（真实字节进度） |
| 进入前外壳是否被屏蔽 | `inert = true`（不可点击、不可读屏） |
| 就绪信号 | 舞台上报「装配完成 + 首个有效帧」后封面才出现「进入探索」 |
| 就绪耗时（本地资产） | **0.61 s ～ 1.24 s** |
| 进入后 | 封面卸载、`inert = false`、顶栏只有品牌与「关于」 |

封面不自动进入、不自动淡出；加载超过 45 s 会提示检查网络并给出「重新加载」。

### Q2 能不能点选结构

| 场景 | 结果 |
| --- | --- |
| 装配态（未拆解）点大脑所在的屏幕位置 | 命中 `body-shell`（皮肤确实挡在前面），面板如实显示「体表（皮肤）· 体表与区域解剖」，并写明 BodyDay 没有为它单独编写内容 |
| 按 `Esc` | 选中清空（`focusTargetId = null`、`isolate = false`），回到本页默认取景 |

### Q3 拖动「拆解」是不是真的拆解

| 进度 | 可见网格数 | 外壳不透明度 | 说明 |
| --- | --- | --- | --- |
| 0% | 984 | 1.000 | 完整人体，皮肤不透明 |
| 25% | 984 | **0.316** | 皮肤渐进半透明，内部结构开始显现 |
| 50% | **748** | 0 | 外壳（236 网格）已移出可见集合与射线层 |
| 100% | 748 | 0 | 各解剖层径向分离，整体仍在画面内 |

位移量由 `progress` 重新计算并覆盖（从不累加），纯函数测试覆盖「反复 0→1→0→1 不累计偏移」。镜头随位移后的整体包围盒联动取景（实测 3.05 → 3.25），完全拆解时人体没有飞出画面——这正是上一轮技术验证踩到的缺陷，本轮已用「单组半径上限 + 相机联动」双重护栏修掉。

### Q5 器官能不能进到细胞

| 链路 | 关系类型 | 按钮文案 | 实测 |

### Q7 还差什么（如实）

1. **移动端**只在浏览器视口 390×844 下检查过响应式、抽屉收放与无横向溢出（实测 `scrollWidth = 390 = viewport`），**未在真机 / 模拟器截图验收**。
2. **真实 GPU 帧率未采集**：自动化验收跑在 SwiftShader 软件渲染下，读数不能代表真实设备表现。
3. **拆解的产品级视觉分离仍在打磨**：分层位移与外壳渐进隐去已落地并实测可见，但内部层间距还可以继续加大（当前每层额外位移 = 人体半径 × 0.17）。
4. 平台报名与提交仍待人工完成（截止 2026-10-18）。

## 4. 本轮修复的真实缺陷（都由验收暴露，已修并有读数）

| 缺陷 | 现象 | 修复 |
| --- | --- | --- |
| 探针屏幕坐标过期 | 相机还在插值时上报投影坐标，按该坐标点击会落空 | 状态变化时上报一次 + **相机停稳后由渲染循环再上报一次** |
| 隔离读数过期 | 探针依赖里缺少 `isolate` / 系统过滤，器官页读到的可见网格数停在上一次的值（三个器官页都读成 169） | 依赖补全；修复后实测大脑 169 / 心脏 4 / 脾脏 1 |
| 透明外壳仍挡点击 | 仅设 `visible = false` 不能保证 three 的射线检测跳过它 | 同时把不可见网格移出第 0 层（`layers.disable(0)`） |
| 大面积材质重编译 | 每次进度变化都对 236 个外壳网格设 `needsUpdate` | 仅在 `transparent` 真正翻转时重编译 |
| 器官页孤页 | `/organ/*` 只能手输网址到达 | 在人体总览选中器官后给出「进入器官页」入口 |
| 局部结构措辞误导 | 在大脑页点到某个脑区时显示「还没有为它建立独立的科普卡片」 | 改为「局部结构 + 归属于本页主体」的如实说明 |

## 5. 为什么没有把「渐进显影」当作需求四

需求四要求的是**真实几何位移**。本轮实现的是：读取 GLB 的 `extras` 得到每个网格的 `anatomyId` / `anatomyParentId` / `anatomySystem`，按可位移结构组对**真实网格位置**做径向平移，并按解剖系统分层，配合体表外壳的渐进隐去。位移直接作用在三维对象上，且是「组装—拆解」可逆的连续插值。

因此需求四的口径是：**机制已验证并落地（真实几何位移 + 外壳隐去 + 拆解后仍可点选）**；**产品级视觉分离仍在继续打磨**（层间距、聚焦优先级）。文档与面板均不把它称作「渐进显影」，也不声称「每一个网格都能单独拆卸」——实际按结构组位移的是 984 个网格（749 个唯一结构）。
